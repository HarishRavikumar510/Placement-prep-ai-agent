# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/placement-ai-agent.git
```

---

## Navigate to Project

```bash
cd placement-ai-agent
```

---

## Install Dependencies

```bash
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file:

```env
VITE_GEMINI_API_KEY=your_api_key_here
```

---

# ▶️ Run Application

```bash
npm run dev
```
